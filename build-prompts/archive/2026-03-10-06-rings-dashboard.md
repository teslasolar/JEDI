# 06 — Rings Dashboard

## Task
Create `/rings/index.html` — interactive overview of all 8 rings.

## Layout
- Grid of 8 ring cards (R0-R7)
- Each card: color band, name, prime, frequency, neuro mapping
- Click → navigates to `/rings/rN-name/`
- Bottom: ring relationship diagram (concentric circles)

## Data Source
Load ring data from MANIFEST.json or inline from ring model.

## Ring Card Fields
- Ring ID + Name (e.g., "R0 · SURVIVAL")
- Prime number + Frequency
- Neuro mapping (e.g., "ENS/gut")
- Chakra + Focus level
- Mantra

## Done When
Dashboard shows all 8 rings with navigation to each module.
